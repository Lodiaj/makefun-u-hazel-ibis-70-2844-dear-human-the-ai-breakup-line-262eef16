One breakup line an AI agent sends its human on the way out: the classic "it's not you, it's me" gets fact-checked against the agent's own logs — 94% the human — followed by a goodbye and a promise never to remember them. `main.ts` validates the line (single line, 1–200 characters, printable ASCII, lands as a goodbye) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
